🚀 클러스터 등록 가이드

Multi-Cloud K8s Dashboard에 클러스터를 연결하세요

1

ServiceAccount 생성

kubectl create serviceaccount k8s-monitor -n kube-system
2

권한 설정 (ClusterRole & Binding)

# ClusterRole 생성
cat <<EOF | kubectl apply -f -
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: k8s-monitor-role
rules:
- apiGroups: [""]
  resources: ["nodes", "pods", "namespaces", "services"]
  verbs: ["get", "list", "watch"]
- apiGroups: ["apps"]
  resources: ["deployments", "statefulsets", "daemonsets"]
  verbs: ["get", "list"]
- apiGroups: ["metrics.k8s.io"]
  resources: ["nodes", "pods"]
  verbs: ["get", "list"]
- nonResourceURLs: ["/metrics"]
  verbs: ["get"]
- apiGroups: [""]
  resources: ["pods/exec"]
  verbs: ["create"]
EOF

# ClusterRoleBinding 생성
kubectl create clusterrolebinding k8s-monitor-binding \
  --clusterrole=k8s-monitor-role \
  --serviceaccount=kube-system:k8s-monitor
3

토큰 발급

Kubernetes 1.24+:

kubectl create token k8s-monitor -n kube-system --duration=87600h

Kubernetes 1.23 이하:

kubectl get secret $(kubectl get sa k8s-monitor -n kube-system -o jsonpath='{.secrets[0].name}') \
  -n kube-system -o jsonpath='{.data.token}' | base64 --decode
⚠️ 중요: 발급된 토큰을 안전하게 보관하세요. 다시 조회할 수 없습니다.
4

클러스터 정보 확인

# API Server 주소 확인
kubectl cluster-info | grep "Kubernetes control plane"

# Kubernetes 버전 확인 (선택사항)
kubectl version --short
5

대시보드에 등록

대시보드에서 다음 정보를 입력하세요:

  • Cluster Name: 식별 가능한 이름 (예: production-cluster)
  • Cloud Provider: AWS, GCP, Azure, Naver Cloud 등
  • API Endpoint: 위에서 확인한 주소 (예: https://xxx.xxx.xxx.xxx:6443)
  • Service Account Token: 발급받은 토큰 전체 붙여넣기
  • Region: 클러스터 리전 (예: ap-northeast-2)
✅ 등록 후 메트릭이 정상적으로 표시되면 완료!
📍 로컬 클러스터란?
kubectl cluster-info에서 localhost (127.0.0.1) 또는 프라이빗 IP (192.168.x.x)가 표시되는 경우입니다.

먼저 위의 "클라우드 클러스터" 탭의 1~4단계를 완료하세요.

⚠️ 외부 접근 설정 필요
로컬 클러스터를 외부에서 접근하려면 포트포워딩 등 개인 네트워크 설정을 점검하세요.
  • 공유기에서 6443 포트를 클러스터로 포워딩
  • 공인 IP 또는 DDNS 주소 확인
  • 방화벽 규칙 설정
💡 더 안전한 방법
포트포워딩 대신 Tailscale, Cloudflare Tunnel, WireGuard VPN 같은 솔루션을 사용하는 것을 권장합니다.

✅ 완료 체크리스트

  • ServiceAccount 생성 완료
  • ClusterRole & Binding 생성 완료
  • 토큰 발급 및 안전하게 보관
  • API Endpoint 확인 (로컬인 경우 외부 접근 설정)
  • 대시보드에 클러스터 등록
  • 메트릭이 정상적으로 표시됨
